# CronPaw 设计主张

CronPaw 是一个安卓原生日历，Jetpack Compose + Material 3 Expressive，设计语言来自 Yoin（`~/Developer/Yoin/docs/design.md`），和 PiliPaw、WeiPaw 是一家。它把 Notion 数据库和系统日历放在同一条时间线上。名字致敬 Notion Calendar 的前身 Cron。这份文档是 UI 和交互决策的依据；代码和它冲突时以它为准。

交互原型（owner 2026-10-23 逐条确认）：https://claude.ai/artifact/31c6Y9gDq26WQ71qSoXcXF

## 0. 已定（owner，2026-10-23）

- 开源，GPL-3.0，包名 `com.gpo.cronpaw`。不上架，不收费。
- **要赢 Notion Calendar 安卓版的三件事**：秒开（冷启动先画本地缓存，网络在后台）、小组件跟得上（日历一变就刷新）、Notion 数据库是一等公民（手机上就能添加和配置）。会议功能（Meet 链接、别人的忙闲）不做。
- **谷歌日历走系统日历**（`CalendarContract`），不碰 Google OAuth；手机上登录的账号自动都在，同步交给系统。
- **Notion**：v0.1 用内部集成令牌（设置里粘贴，数据库分享给集成即可）；以后换 `notion-oauth-relay` Worker 的公开 OAuth。
- **语音**：默认系统 `SpeechRecognizer`；设置里填自己的 ElevenLabs API Key（BYOK）后用 Scribe v2。
- 专注模式（接管手机、切 Mode / 勿扰、无障碍权限）和 MD3E 番茄钟：以后做，现在只留入口位置。

## 1. 主屏

- **顶栏**：左边侧栏按钮；「10月」大字，右边一枚小胶囊上下叠着当前可见的第一天和最后一天（不用「~」「–」）；右边搜索、今天。今天按钮在今天可见时是浅色，翻走后变实心，点一下回到今天。
- **视图**：1 天 / 2 天 / 3 天（手机默认 3 天），平板竖屏加「周」（周一开始）。左右滑整页翻（按视图天数），弹簧落位。
- **时间线**：小时带用隔行色块，不画横线。现在线红色，只在今天那列加粗加点。时间重叠的条目左右并排，不挤成一团。全天条目在日期下面一行。
- **Notion 待办**前面一个圆圈，点一下直接完成（勾 + 删除线 + 变淡），写回 Notion 的完成状态。

## 2. 顶部轮换卡

- 内容：自动的「下一个」+ 用户置顶的事项，最多三条，约 3.8 秒轮换一次。
- 详略：左边一枚色块（自动的是圆，置顶的是圆角方块带图钉）、一行小标签、一行标题；右边一个加粗大数字加安静的小标签（「2:52」「后开始」）。右缘一条竖向小页码，当前那格拉长。
- 轮换动画：新的一条从下方滚入，带一点模糊和回弹；卡片底色同时用效果弹簧过渡到这条事项的颜色。
- 左右滑：卡片带一点倾斜飞出，下一条补上。三条都滑掉，日历用弹簧向上占满。滑掉只对这次打开有效。
- 点卡片：底部面板列出全部（自动 + 置顶 + 滑掉的），可置顶 / 取消，滑掉的可「放回」。
- 置顶入口：条目详情底部的图钉按钮。

## 3. 侧栏

- 账号头像、设置。视图切换是连体按钮组。
- 「Google · 系统日历」一块，「Notion」一块。每个日历 / 数据库一行：色块就是开关（实心 = 显示，空心描色 = 隐藏），不用小眼睛。
- Notion 数据库行显示「N 未排期」；底部「添加数据库」。

## 4. 条目详情（底部面板）

- 默认只显示**时间**和**状态**（状态是连体按钮组）。
- 右下角省略号：列出这个数据库的**全部属性**，每个属性一只小眼睛，点一下显示 / 隐藏。设置按数据库保存。
- 底部：「打开页面」（Notion 页面 / 系统日历事件）、图钉、省略号。
- 左上一个大的完成按钮，完成时方形变圆、填充主色。

## 5. 添加数据库（首次配置）

选数据库 → 选颜色 → 日期用哪个属性 → 哪个状态算「完成」→ 用小眼睛选详情里显示哪些属性（默认只开时间和状态）。

## 6. 新建

- **点加号**：浮出托盘，三根时间条 15 分钟 / 30 分钟 / 1.5 小时（条长对应时长），下面一条自定义条。
- **自定义条**：没点亮时，横着拉 = 直接调长度（松手保存），往上拉 = 拿起来拖到日历。点一下点亮（描边 + 轨道染色），这时任何拖动都是调长度，点别处退出。5 分钟一格，每格 `tick()`，范围 5 分钟到 4 小时。
- **拖到日历**：15 分钟吸附，每换一格 `tick()` 并轻弹一下；松手 `lowTick()`。
- **语音页**：顶部一排快捷入口（简单专注 25 分、简单工作 1 小时……，设置里可编辑）；时间；保存到「日历 / Notion」+ 具体日历；麦克风。**必须手动按停止**才结束识别。
- **确认页**：识别出的标题、时间、目标数据库的默认属性。保存按钮从左往右填满，4 秒内不碰屏幕就自动保存；碰一下倒计时停。保存后底部「已加入」+「编辑」，点编辑回到确认页。
- **长按加号**：手动输入。下方实时拆出日期、时间、时长、标题四块（「明天下午3点半 和小林喝咖啡 1.5小时」）。

## 7. 搜索

- 模糊匹配（子序列，连续命中和词首加分），命中的字高亮。
- 输入日期时，候选**保持当前视图**，不跳到别的视图：3 天视图搜 10.17 → 10.16–10.18（居中）、10.17–10.19（从这天开始）、10.15–10.17（到这天为止）、另一年的同一范围；周视图 → 周一开始的那一周 + 另一年。
- 年份：`10.17` = 下一个 10.17；`23.10.17` = 2023 年；`31` = 下一个 31 号。

## 8. 小组件

今日列表（待办圆圈、时间）、「下一个」倒计时、「未排期」数。日历变化时用 `JobScheduler` 的内容 URI 触发刷新，到下一个事件开始 / 结束时用闹钟刷新。小组件里不轮换。

## 9. 规则（继承 Yoin / WeiPaw）

- 原生组件优先：`LoadingIndicator`、连体 `ButtonGroup` / `ToggleButton`、`ModalBottomSheet`、原生 `SearchBar`。
- 只用弹簧（`YoinMotion` / `MaterialTheme.motionScheme`），状态变化都有过渡；系统关动画时原地淡入淡出。
- 色块分层，不用描边、分割线、outlined 输入框，阴影为 0。连续圆角。Google Sans Flex，Yoin Symbols。
- 文案只做标签：不写解释句、不提问、不鼓励；不用「·」拼接；数字 = 加粗的值 + 安静的标签。
- 全面 edge-to-edge，底部面板也是。大屏认真做：平板竖屏 Medium（周视图 + 侧栏常驻），横屏 Expanded（详情在右栏原地展开）。
- 触感一律 `RichHaptics`。
